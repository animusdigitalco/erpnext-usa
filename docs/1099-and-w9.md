# 1099 and W-9 Handling

## What core already has

When a company with country "United States" exists, ERPNext core adds an `irs_1099` checkbox to Supplier and ships an IRS 1099 report keyed to it. That's the whole story in core: no NEC/MISC distinction, no W-9 tracking.

## What this app adds

A **US Tax Reporting** section on Supplier (fields namespaced `us_*` so they never collide with core):

| Field | Purpose |
| --- | --- |
| 1099 Form | `1099-NEC` (most contractors) or `1099-MISC` (rents, royalties, other) — empty means no 1099 |
| TIN Type | EIN or SSN, so year-end filing data is complete |
| W-9 on File | The compliance checkbox: did you actually collect it? |
| W-9 Document | Attach the signed W-9 itself |

## Suggested workflow

1. Onboard a new contractor → request the W-9 before the first payment (the IRS expects you to have it before you pay, not before you file).
2. Attach it, tick **W-9 on File**, set **1099 Form** and **TIN Type**.
3. Book their work to **6090 Contract Labor (1099)** (or any expense account — the classification lives on the supplier, not the account).
4. At year end, filter Suppliers by 1099 Form and run payment totals per supplier for the calendar year. Core's IRS 1099 report works alongside; tick core's `irs_1099` too if you use it.

## Disclaimer

Thresholds and form rules change. Confirm current-year requirements with your CPA; this app tracks data, it does not give filing advice.
